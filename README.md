# 熊撃 - KUMAGEKI

熊の襲撃から村を守るタワーディフェンスゲームです。

## ゲーム概要

プレイヤーは熊緊急対策室として、与えられた資金の中で、罠やハンターを配置し、襲来する熊から村を守ります。\
単純に熊を倒すだけでなく、世論を考慮した立ち回りが求められるゲームです。

## ゲームの流れ

### 1. 準備フェーズ

- 制限時間内に罠やハンターを配置します。
- 熊の出現場所を確認し、守備を整えます。

### 2. 襲撃フェーズ

- 複数のウェーブにわたって熊が襲来します。
- 配置したユニットが自動的に応戦し、村の家々を守ります。
- 全ての家が破壊されるとゲームオーバーとなります。

### 3. リザルトフェーズ

- ウェーブごとの撃退・捕獲数・世論などを確認し、次のウェーブへの準備、または最終結果へと進みます。

## 操作方法

このゲームは**コントローラーでのプレイ**が必須です。操作によってボタンの役割が異なります。

### 🎮 操作一覧

| ボタン           | カメラ操作                   | ユニット配置・操作         |
| :--------------- | :--------------------------- | :------------------------- |
| **A ボタン**     | ユニットを配置               | 選択・設置                 |
| **B ボタン**     | 選択キャンセル               | キャンセル・メニュー閉じる |
| **X ボタン**     | なし                         | メニュー開閉               |
| **Y ボタン**     | なし                         | 準備フェーズスキップ       |
| **LT / RT**      | カメラ視点変更               | -                          |
| **左スティック** | カーソル移動（ユニット選択） | カーソル移動               |
| **START**        | ポーズ                       | ポーズ                     |

> **カメラ操作について** \
> LT / RT ボタンを使用することで、4つの異なるカメラ視点を切り替えてフィールドを確認できます。

> **コントローラーが反応しない場合** \
> ゲーム開始前にコントローラーが接続されていることを確認してください。Xbox / PlayStation 形式のコントローラーに対応しています。

## 主要システム

- **資金**
  - 熊を駆除・捕獲することで報酬が得られ、新しい罠の設置やハンターの雇用に使用できます。
- **世論**
  - プレイヤーの行動によって世論が変動し、ゲームに影響を与えます。
- **畑**
  - 襲撃フェーズ中に資金が増えます。
  - 畑のレベルを上げることで増加量が上がります。
- **配置ユニット**
  - **檻**: 熊を捕獲し、報酬を得るための主要な手段です。
  - **電気柵**: 通行を妨害したりダメージを与えたりします。
  - **ハンター**: 索敵・攻撃を行い、直接的に熊を排除します。

## プレイ方法

1. 右側の [Releases](https://github.com/gaxit-project/GameXCross_Bear_Team3/releases) から最新の zip ファイルをダウンロードします。
2. ダウンロードしたファイルを解凍し、`Game` フォルダを開きます。
3. `KUMAGEKI.exe` を実行するとゲームが開始されます。

> **Windows の保護機能が表示された場合**
> 実行時に「Windows によって PC が保護されました」と表示される場合は、「詳細情報」→「実行」を選択してください。

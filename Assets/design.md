# 仕様
## ゲーム進行の順序
### 準備フェーズ (Setup Phase)

1. **カウントダウン管理**
   - `GameBalanceData.setupTime`（デフォルト30秒）を UniRx `Observable.Interval` で減算しつつ `GameState.Setup` を維持する。
   - タイマー表示は UI Textに秒単位で反映する。
   - ポーズ中は `Time.timeScale` を0にしてカウントを停止し、復帰で再開する。
2. **プレイヤー操作**
   - 檻・ハンター・電気柵を置くことができる。
   - カメラを移動できる場所が4箇所あり、視点移動することができる。
3. **AIの挙動**
   - ハンターは移動・索敵・攻撃コマンドを無効化する。
   - ハンターAIは `GameState.Setup` を監視し、`NavMeshAgent` 停止・索敵無効・アニメーション待機ループに遷移。
4. **配置とリソース準備**
   - 熊の初期スポーン位置を確定し、出現場所がある程度分かるように印を付ける。
   - マップ上のオブジェクト（家や罠など）の初期状態をリセット。
5. **フェーズ遷移トリガー**
   - ゲーム開始直後やリトライ時は必ずこのフェーズを経由し、スキップは不可。
   - タイマーが0になると `StartBattlePhase()` をコールして自動的に襲撃フェーズへ移行。
6. **デバッグ・チューニング**
   - `setupTime` をインスペクタで調整可能にして開発時に短縮テストを実施。
